\subsection{Reproduction Entry Points}

The route table is reproduced with:
\begin{lstlisting}[language=bash]
python docs/paper/reproducibility/route_benchmark.py
\end{lstlisting}
The diagnostic vision pipeline is implemented by \path{perception/vision/benchmarks/batch_benchmark.py}; it requires the local clip corpus, the two committed ONNX graphs, OpenCV, NumPy, and ONNX Runtime. A publication artifact should add a lockfile, complete model hashes, a hardware/OS manifest, raw per-frame timing output, and a non-interactive command that regenerates every table and figure.
