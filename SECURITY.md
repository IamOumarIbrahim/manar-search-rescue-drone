# Security Policy

## Reporting a Security Issue

If you discover a security vulnerability or accidentally exposed sensitive
information related to MANAR, **do not open a public issue**.

Please report it privately to **Oumar Ibrahim** through an available private
contact method associated with this repository or GitHub profile.

Include, where possible:

- a description of the issue;
- affected files or components;
- steps to reproduce it;
- any relevant logs, screenshots, or evidence.

Please allow reasonable time for the issue to be reviewed before publicly
disclosing it.

## Scope

MANAR is an independently developed project with a proprietary core and
selected components that may be released under separate licenses.

Security reports concerning publicly available MANAR software,
documentation, infrastructure, or exposed sensitive information are welcome.
