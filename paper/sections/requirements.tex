\section{System Requirements}

MANAR is engineered to satisfy operational and safety constraints for aerial search-and-rescue.

\subsection{Operational Envelope and Performance Targets}
The system targets an operational flight envelope tailored for rugged wilderness and desert environments:
\begin{itemize}
    \item \textbf{Search Endurance ($SYS\text{-}G\text{-}02$):} At least 1.0 hour of continuous active search under a nominal payload and representative sensor duty cycle.
    \item \textbf{High-Altitude Operational Ceiling ($SYS\text{-}G\text{-}01$):} Takeoff, climb, and stable search up to $2000.0\text{ m}$ AMSL with designated payload.
    \item \textbf{Speed Presets and Limits:} Four discrete velocity presets ($v_Q, v_A, v_I, v_H$) bounded by software velocity clamp $v_{\max}$ and altitude ceiling $H_{\max}$. Takeoff climb target is specified by $H_{\mathrm{launch}}$.
\end{itemize}

\subsection{Terrain-Adaptive Search Strategy}
Search path generation adapts to local terrain geometry:
\begin{itemize}
    \item \textbf{Open / Flat Terrain:} Parallel-track lawnmower sweeps parameterized by sector width $W$, height $H$, and row spacing $\Delta y$.
    \item \textbf{Mountainous / Steep Terrain:} Terrain-aware contour-following paths maintaining nominal sensor standoff distance.
\end{itemize}

\subsection{Deterministic Contingency and Failsafe Rules}
The flight system enforces deterministic contingency responses:
\begin{itemize}
    \item \textbf{Command-Link Loss ($SYS\text{-}R\text{-}01$):} Upon link interruption, the aircraft maintains a temporary hold or verified safe route. If reconnection fails within a configurable timeout, autonomous RTL is engaged.
    \item \textbf{Energy Failsafe ($SYS\text{-}R\text{-}02$):} Sufficient return energy is continuously reserved. When return capability is compromised, RTL is triggered; if return is unachievable, an emergency landing sequence executes while preserving coordinates.
    \item \textbf{GNSS Degradation:} Transitions to attitude hold and local clearance sensing without making unverified absolute radar localization claims.
    \item \textbf{Environmental Limits:} Dangerous wind, icing, or propulsion anomalies automatically trigger mission abort or RTL.
\end{itemize}
