\section{Conclusion}

This paper presented MANAR (Multi-sensor Autonomous Navigation and Aerial Rescue), a supervised-autonomy SAR system architecture built upon a deterministic C++ control core, Haversine geographic navigation, an $O(n^2)$ greedy search route optimizer with operator override privilege, and an ONNX Runtime C++ visual candidate detector (YOLO11n). By maintaining a strict distinction between the implemented functional C++ prototype, selected software state ownership architecture, and planned perception extensions, the paper establishes a grounded technical baseline. Functional prototype verification confirmed deterministic control behavior, search-plan locking, automatic Return-to-Launch (RTL) navigation preemption, and real-time visual candidate inference ($29.2\text{ ms}$ latency with zero false positives on clutter). MANAR establishes a foundation for dependable, human-supervised aerial search-and-rescue robotics.
