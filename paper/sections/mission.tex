\section{Mission Architecture and Control Flow}

MANAR coordinates flight execution through a modular navigation hierarchy and deterministic mission logic.

\subsection{Navigation vs.\ Payload Sensor Layering}
To safeguard flight stability, MANAR decouples flight-critical navigation sensors from mission payload instrumentation:
\begin{itemize}
    \item \textbf{Navigation Sensor Suite:} Dual GNSS/GPS, IMU, 3-axis magnetometer, barometric altimeter, downward radar altimeter (terrain-relative clearance), and forward/lateral obstacle radar interfacing with a Pixhawk-class autopilot.
    \item \textbf{Payload Sensor Suite:} Dedicated $24\text{ GHz}$ rescue FMCW radar, thermal LWIR, RGB, low-light IR cameras, digital MEMS acoustic array, and passive RF software-defined radio.
\end{itemize}

\subsection{Candidate Approach and Hover Verification Sequence}
Upon wide-area candidate detection, the system executes a deterministic 9-step verification sequence:
\begin{enumerate}
    \item \textbf{Evidence Registration:} Log candidate coordinates and sensor detections.
    \item \textbf{Constraint Validation:} Check geofence, terrain clearance, wind, and battery reserve.
    \item \textbf{Velocity Deceleration:} Automatically reduce horizontal speed to $v_I$.
    \item \textbf{Safe Descent:} Descend to nominal inspection altitude $H_{\mathrm{inspect}}$.
    \item \textbf{Positioning Orbit:} Execute bounded inspection orbit if required.
    \item \textbf{Gimbal Aiming:} Orient imaging, radar, and acoustic sensors toward target.
    \item \textbf{Hover Stabilization:} Transition to stationary hover ($v_H = 0$).
    \item \textbf{Synchronized Verification:} Execute acoustic call-and-listen cycles while evaluating Mamba temporal fusion.
    \item \textbf{Alert Escalation:} Trigger ground station alert upon meeting fusion threshold for human review.
\end{enumerate}

\subsection{Prototype Control Flow \& RTL Semantics}
In the current C++ prototype, multi-location search plans execute sequentially via \texttt{mission.cpp}. When sector $k$ completes ($1 \le k \le N$), the control loop advances $k \leftarrow k+1$ and re-initializes sweep counters. Upon completion of all $N$ sectors or upon failsafe trigger, Return-to-Launch (\texttt{activateRTL()}) is commanded, resetting navigation destination to home coordinates (\texttt{isdestinationhome = true}).
