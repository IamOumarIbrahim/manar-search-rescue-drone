\subsection{Problem Formulation}
Let the operator define a set of $n$ search locations:
\begin{equation}
L = \{L_1, L_2, \dots, L_n\}, \qquad L_i = (\phi_i, \lambda_i)
\end{equation}
Let $p_0 = (\phi_{\mathrm{drone}}, \lambda_{\mathrm{drone}})$ denote aircraft coordinates at plan lock time, and $h = (\phi_{\mathrm{home}}, \lambda_{\mathrm{home}})$ denote home base coordinates. Naive exhaustive permutation enumeration requires evaluating $n!$ waypoint orderings~\cite{applegate2006traveling}, which grows factorially and is impractical for onboard execution.

\subsection{Greedy Nearest-Neighbor Formulation}
MANAR implements an $O(n^2)$ greedy nearest-neighbor algorithm in \texttt{route\_optimizer.cpp}. Starting from initial position $p_0$, the algorithm iteratively selects the closest unvisited location.

Let $U_k$ denote the set of unvisited locations at step $k$, with $U_0 = L$. For $k = 0, 1, \dots, n-1$:
\begin{equation}
p_{k+1} = \underset{x \in U_k}{\operatorname{argmin}} \; d(p_k, x)
\end{equation}
The selected location $p_{k+1}$ is appended to the ordered route sequence, and the unvisited set is updated:
\begin{equation}
U_{k+1} = U_k \setminus \{p_{k+1}\}
\end{equation}

Home location $h$ is excluded from candidate selection iterations. The final leg $d(p_n, h)$ is included when calculating total planned transit distance $d_{\mathrm{total}}$, without inserting $h$ into the search sequence:
\begin{equation}
d_{\mathrm{total}} = d(p_0, p_1) + \sum_{k=1}^{n-1} d(p_k, p_{k+1}) + d(p_n, h)
\end{equation}

\subsection{Combinatorial Complexity}
The total number of candidate distance evaluations $N_{\mathrm{eval}}$ across $n$ locations is:
\begin{equation}
N_{\mathrm{eval}} = \sum_{k=0}^{n-1} (n - k) = \frac{n(n+1)}{2} = O(n^2)
\end{equation}
For $n = 8$, nearest-neighbor selection requires 36 candidate distance evaluations ($8+7+\dots+1=36$), avoiding the $8! = 40\,320$ permutations of naive exhaustive search.

\subsection{Operator Override Privilege}
In tactical operations, operators may possess domain intelligence (e.g., wind drift, barrier terrain) that overrides geometric proximity. MANAR preserves operator authority:
\begin{equation}
\text{Route} = \begin{cases}
\operatorname{GreedyOpt}(p_0, L, h), & \text{if operator selects } Y \\
L, & \text{if operator selects } N
\end{cases}
\end{equation}
Disabling optimization ($N$) preserves exact input ordering ($p_k = L_k$). In both cases, \texttt{control.exe} freezes the plan (\texttt{searchplanlocked = true}) upon submission. In the current prototype, a locked plan remains immutable until the prototype reset path clears the lock.
