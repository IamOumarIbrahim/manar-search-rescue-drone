\subsection{Separation of Software Layers}
MANAR enforces architectural separation across decoupled operational layers:
\begin{itemize}
    \item \textbf{C++ Control Core (\texttt{core/}):} Executes deterministic mission state machine, kinematic flight bounds, and greedy route optimization.
    \item \textbf{Visual Perception Library (\texttt{computer\_vision/}):} High-performance ONNX Runtime C++ detector module producing instantaneous candidate detections.
    \item \textbf{Operator Interface (React/TypeScript):} Selected web-based operator terminal communicating via WebSocket + JSON IPC protocol.
    \item \textbf{Temporal Fusion Engine (Mamba SSM):} Planned multi-modal evidence association and candidate alert escalation filter.
\end{itemize}
