\subsection{Separation of Software Layers}
MANAR enforces architectural separation across three distinct operational layers:
\begin{itemize}
    \item \textbf{C++ Control Core (\texttt{control.exe}):} Operational prototype. Executes deterministic control, kinematic safety clamps, and route planning.
    \item \textbf{Operator Interface (React/TypeScript):} Selected GUI. Communicates asynchronously via WebSocket + JSON IPC protocol.
    \item \textbf{Perception Pipeline (Python/PyTorch):} Planned ML perception models and multisensor evidence fusion.
\end{itemize}
